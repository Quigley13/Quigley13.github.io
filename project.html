Projects

Here are some of my projects.

Critical Vulnerabilities at ShieldNova

This was my system security final project where my group and I looked at different vulnerabilities in a simulated environment and explained how they could be exploited. We worked through things like SQL injection, password cracking, file upload issues, binary weaknesses, and network traffic analysis, then connected all of that to the real security risks and possible fixes. It was a really good project for understanding how different security problems can connect together in one system.

Adobe Flash Vulnerability CVE-2016-4117

In this project, my group and I researched and presented on the Adobe Flash vulnerability CVE-2016-4117. We broke down what the vulnerability was, why it was serious, how attackers could use it, and what kind of impact it could have on a system. This project helped me get more comfortable explaining a real cybersecurity issue in a way that connects the technical side with the bigger picture.

Sorting Project

This project focused on comparing different sorting algorithms and seeing how they performed with different types of data. My group and I tested multiple sorts, tracked timing and compares, and looked at how the algorithms handled random, almost sorted, reverse sorted, and duplicate-filled arrays. It was a solid project for learning more about algorithm efficiency and seeing how class concepts actually play out in code and data.
